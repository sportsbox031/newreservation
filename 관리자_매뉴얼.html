경기도체육회 스포츠박스 예약시스템

1. 설정 탭 (중요)

1.1 시스템 기본설정

1하루 최대 예약수 설정

시스템 기본설정에서 하루 최대 예약수를 설정합니다.

1.2 특정일 예약관리

2특정일 예약 갯수 조정

  1. 특정일 예약관리 섹션 선택
  2. 날짜 선택
  3. 최대 예약수 조정

1.3 예약불가 날짜관리

3휴가/휴무일 설정

  1. 예약불가 날짜관리 섹션 선택
  2. 날짜 선택
  3. 추가 버튼 클릭

1.4 예약 시작/종료 관리

4예약 시작/종료 설정

모든 설정 완료 후:

  1. Priority 회원 예약 시작: 예약일에 맞추어 Priority 회원 예약시작 버튼 클릭
  2. 전체 예약 시작: 전체 예약시작일에 전체 예약시작 버튼 클릭
  3. 전체 예약 종료: 예약이 종료되었을 경우 전체 예약종료 버튼 클릭

⚠️ 중요

모든 설정은 월별로 세팅을 따로 해야합니다.

2. 예약관리 탭

2.1 뷰 선택

뷰탭에서 달력뷰 또는 리스트뷰를 선택하여 예약을 확인할 수 있습니다.

2.2 달력뷰 사용

  1. 달력에서 해당 날짜 클릭
  2. 상세 예약내역 확인
  3. 승인 또는 거절 선택
  4. 승인/거절 시 회원 단체에게 자동으로 알림톡 발송

3. 공지사항 관리

3.1 권한

  • admin (전체관리자): 모든 권한 보유
  • 지역관리자: 다른 관리자가 작성한 글의 수정/삭제 권한 없음

3.2 공지사항 작성

1새 공지사항 버튼 클릭하여 작성

3.3 텍스트 형식

기본텍스트, HTML, 마크다운 형식을 지원합니다.

3.4 첨부파일

  • 최대 3개까지 가능
  • 파일당 최대 5MB까지 가능

3.5 공지대상 및 중요공지

  • 공지대상 특정지역 설정: 홈화면에 지역 색상 뱃지가 표시됩니다.
  • 중요공지 체크: 공지사항 목록 최상단에 표시됩니다.

4. 팝업관리

4.1 팝업 만들기

1새 팝업 만들기 버튼 클릭하여 작성

4.2 텍스트 형식

기본텍스트, HTML, 마크다운 형식을 지원합니다.

4.3 날짜 설정

  • 시작날짜: 팝업 표시 시작일 입력
  • 종료날짜: 입력하지 않을 경우 계속 노출됩니다.

4.4 표시 순서

표시 순서를 정하고 내용을 작성합니다.

5. 회원관리 탭

5.1 회원 등급 자동 부여

등급 자동 부여 규칙

  • 아동돌봄시설: 자동으로 Standard 등급 부여
  • 학교:
    • 전교생수 240명 이하 또는 11개 학급 이하 → Priority 등급
    • 그 이외 → Standard 등급

5.2 회원 등급 수동 변경

1등급 변경 요청 확인

회원단체에서 등급 변경 요구 시 확인 후 관리자가 회원관리 탭에서 수동으로 변경 가능합니다.

⚠️ 중요 - 전교생수/학급수 변경

혼동 방지를 위해 회원단체에게 계정관리에서 전교생수, 학급수 변경을 요청하세요.

  • 회원단체가 전교생수/학급수를 변경해도 등급은 자동으로 변하지 않습니다.
  • 등급 변경은 관리자가 수동으로 변경해야 적용됩니다.
