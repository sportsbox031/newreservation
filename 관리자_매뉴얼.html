1. 시스템 소개

🎯 시스템 목적

경기도 남부 및 북부 지역의 스포츠박스 시설 예약을 효율적으로 관리하기 위한 통합 관리 시스템입니다.

관리자 권한 구조

권한 등급 역할 접근 범위
최고 관리자 (super) 전체 시스템 관리 경기남부 + 경기북부 전체 지역
남부 관리자 (south) 경기남부 지역 관리 경기남부 지역 소속 회원 및 예약만
북부 관리자 (north) 경기북부 지역 관리 경기북부 지역 소속 회원 및 예약만

주요 기능

  • 회원 가입 승인/거부 관리
  • 예약 신청 승인/취소 관리
  • 공지사항 작성 및 관리
  • 홈페이지 팝업 관리
  • 예약 불가 날짜 설정
  • 통계 및 리포트 확인

2. 로그인

1로그인 페이지 접속

또는 직접 URL: https://ggsportsbox.or.kr/auth/login 접속

2로그인 정보 입력

남부 관리자 admin_south admin123 경기남부
북부 관리자 admin_north admin123 경기북부

⚠️ 보안 주의사항

  • 초기 비밀번호는 반드시 변경하세요
  • 비밀번호는 주기적으로 변경하세요
  • 타인과 계정을 공유하지 마세요
  • 공용 PC에서는 로그아웃을 잊지 마세요

4. 회원 관리

4.1 신규 회원 승인

1회원 관리 메뉴 접속

좌측 네비게이션에서 회원 관리 클릭

2승인 대기 회원 확인

상단 탭에서 승인 대기 탭을 선택하면 가입 승인을 기다리는 회원 목록이 표시됩니다.

회원 정보 항목

  • 단체명: 신청한 단체의 이름
  • 담당자명: 담당자 실명
  • 연락처: 휴대폰 번호
  • 이메일: 이메일 주소
  • 지역: 소속 시/도
  • 가입일: 신청 날짜 및 시간

3승인 처리

✅ 승인

  1. 회원 정보를 검토합니다
  2. 승인 버튼 클릭
  3. 확인 메시지가 표시되면 확인 클릭
  4. 승인 완료 시 회원에게 승인 알림톡이 자동 발송됩니다

❌ 거부

  1. 거부 버튼 클릭
  2. 거부 사유를 입력합니다 (필수)
  3. 확인 클릭
  4. 거부 사유가 회원에게 알림톡으로 전달됩니다

💡 승인 거부 사유 예시

  • 경기도 외 지역 단체 (서비스 대상 지역이 아님)
  • 정보 불일치 (실제 단체명과 다름)
  • 연락처 오류 (연락이 되지 않음)
  • 중복 가입 (이미 가입된 단체)
  • 기타 부적격 사유

4.2 승인된 회원 조회

승인 완료 탭에서 승인된 전체 회원 목록을 확인할 수 있습니다.

기능

  • 검색: 단체명, 담당자명으로 검색
  • 필터링: 지역별로 필터링
  • 정렬: 가입일 순, 이름 순 정렬
  • 상세 조회: 회원 행 클릭 시 상세 정보 및 예약 이력 확인

⚠️ 지역 관리자 권한 제한

남부/북부 관리자는 본인의 관리 지역에 속한 회원만 조회 및 관리할 수 있습니다.

  • 남부 관리자: 경기남부 소속 회원만
  • 북부 관리자: 경기북부 소속 회원만
  • 최고 관리자: 모든 지역 회원 조회 가능

5. 예약 관리

5.1 예약 신청 승인

1예약 관리 메뉴 접속

좌측 네비게이션에서 예약 관리 클릭

2승인 대기 예약 확인

상단 탭에서 승인 대기 선택

예약 정보 항목

  • 단체명: 예약한 단체명
  • 예약일: 이용 날짜
  • 시간대: 예약된 시간대 (예: 09:00-09:40)
  • 학년: 참여 학생 학년
  • 장소: 위치
  • 인원: 참가 인원 수
  • 신청일: 예약 신청 날짜

3승인 처리

✅ 승인

  1. 예약 정보를 검토합니다
  2. 시간대 중복 여부를 확인합니다
  3. 승인 버튼 클릭
  4. 확인 메시지 확인 후 확인 클릭
  5. 승인 완료 시 예약자에게 승인 알림톡 자동 발송

❌ 거부

  1. 거부 버튼 클릭
  2. 거부 사유를 입력합니다
  3. 확인 클릭
  4. 거부 사유가 예약자에게 알림톡으로 전달됩니다
  5. 회원의 월간 예약 가능 횟수가 복구됩니다

💡 승인 거부 사유 예시

  • 해당 시간대 예약 마감
  • 시설 점검으로 인한 이용 불가
  • 행사 일정과 중복
  • 정보 오류 (인원 수, 학년 등)

5.2 승인된 예약 조회

승인 완료 탭에서 승인된 모든 예약을 확인할 수 있습니다.

조회 옵션

  • 날짜 필터: 특정 날짜의 예약만 조회
  • 단체 검색: 단체명으로 검색
  • 지역 필터: 지역별 필터링

5.3 취소 요청 처리

1취소 요청 확인

취소 요청 탭을 선택하면 회원이 취소를 요청한 예약 목록이 표시됩니다.

2취소 승인 처리

  1. 취소 요청 사유를 확인합니다
  2. 취소 승인 버튼 클릭
  3. 확인 후 확인 클릭
  4. 예약이 취소되고 회원의 월간 예약 가능 횟수가 복구됩니다
  5. 취소 완료 알림톡이 자동 발송됩니다

⚠️ 중요: 예약 횟수 복구 규칙

  • 승인대기 상태에서 사용자가 직접 취소: 즉시 예약 횟수 복구
  • 승인완료 상태에서 사용자가 취소 요청: 관리자 승인 후 예약 횟수 복구
  • 관리자가 강제 취소: 즉시 예약 횟수 복구

✅ 회원은 한 달에 최대 4일까지 예약 가능하며, 하루에 최대 2개의 시간대를 예약할 수 있습니다.

5.4 강제 취소

긴급한 상황에서 관리자가 직접 예약을 취소할 수 있습니다.

절차

  1. 승인 완료 예약 목록에서 취소할 예약 선택
  2. 강제 취소 버튼 클릭
  3. 확인 클릭
  4. 예약이 즉시 취소됨.

💡 강제 취소 사용 예시

  • 날씨로 인한 운영 중단
  • 행사 일정 변경
  • 예약 정보 오류

5.5 당일 알림톡 자동 발송

✅ 프로그램 당일 리마인더 알림톡

시스템이 자동으로 다음 작업을 수행합니다:

  1. 오늘 날짜로 예약된 승인완료 건을 조회
  2. 해당 예약자들에게 프로그램 이용 당일 안내 알림톡 발송

6. 공지사항 관리

6.1 공지사항 작성

1공지사항 메뉴 접속

좌측 네비게이션에서 공지사항 클릭

2새 공지사항 작성

  1. 우측 상단의 새 공지사항 버튼 클릭
  2. 제목 입력 (최대 100자)
  3. 내용 입력
  4. 중요 공지사항 설정 (체크박스)
    • 체크 시: 상단 고정 및 강조 표시
  5. 저장 버튼 클릭

⚠️ 주의사항

  • 삭제된 공지사항은 복구할 수 없습니다
  • 중요 공지사항은 신중하게 삭제하세요
  • 공지사항은 메인 페이지에 즉시 반영됩니다

7. 팝업 관리

7.1 팝업 생성

1팝업 관리 메뉴 접속

좌측 네비게이션에서 팝업 관리 클릭

2새 팝업 만들기

  1. 새 팝업 만들기 버튼 클릭
  2. 팝업 정보 입력
    • 제목: 팝업 제목 (최대 100자)
    • 내용: 팝업 본문
    • 활성화: 팝업 표시 여부
    • 시작일: 팝업 표시 시작 날짜
    • 종료일: 팝업 표시 종료 날짜
  3. 저장 클릭

7.3 팝업 표시 규칙

📋 팝업 표시 조건

다음 조건을 모두 만족할 때 사용자에게 팝업이 표시됩니다:

  1. 팝업 활성화 상태가 ON
  2. 현재 날짜가 시작일과 종료일 사이
  3. 사용자가 오늘 하루 보지 않기를 선택하지 않음

⚠️ 주의사항

  • 동시에 여러 팝업을 활성화할 수 있습니다
  • 팝업은 메인 페이지 접속 시 자동으로 표시됩니다
  • 종료일이 지나면 자동으로 표시되지 않습니다

7.4 팝업 활용 예시

  • 시스템 점검 안내
  • 예약 마감 공지
  • 이용 주의사항
  • 특별 프로그램 안내
  • 휴무일 공지

8. 설정 관리

8.1 예약 불가 날짜 설정

1설정 메뉴 접속

좌측 네비게이션에서 설정 클릭

2날짜 차단 추가

  1. 날짜 추가 버튼 클릭
  2. 차단할 날짜 선택 (캘린더)
  3. 사유 입력 (예: 시설 점검, 행사 진행)
  4. 저장 클릭

3차단 날짜 관리

조회

  • 설정된 모든 차단 날짜 목록 표시
  • 날짜순 정렬
  • 과거 날짜는 자동으로 비활성 표시

삭제

  1. 삭제할 날짜 선택
  2. 삭제 버튼 클릭
  3. 확인 후 삭제

💡 차단 날짜 설정 시 영향

  • 사용자는 해당 날짜에 예약 신청 불가
  • 캘린더에 차단 표시 (회색 또는 X 표시)
  • 이미 예약된 건은 영향 없음 (별도 취소 필요)

⚠️ 주의사항

  • 차단 날짜 설정 전 기존 예약 여부 확인
  • 기존 예약이 있다면 사전에 취소 처리 필요
  • 긴급 차단 시 예약자에게 별도 연락 권장

8.2 예약 불가 날짜 사용 예시

  • 공휴일 및 연휴
  • 시설 정기 점검일
  • 대규모 행사 진행일
  • 기상 악화 예상일
  • 시설 수리/보수 기간

9. 자주 묻는 질문 (FAQ)

Q1. 승인 대기 중인 예약/회원이 표시되지 않아요

A: 관리자 권한을 확인하세요. 남부/북부 관리자는 해당 지역의 데이터만 볼 수 있습니다.

Q2. 알림톡이 발송되지 않아요

A: 다음을 확인하세요:

  • 회원의 연락처가 올바르게 등록되어 있는지
  • Aligo 서비스 잔액이 충분한지
  • 환경변수(.env.local)가 올바르게 설정되어 있는지

Q3. 예약 횟수가 정확하지 않아요

A: 예약 횟수 계산 규칙:

  • 승인대기 상태: 횟수 차감
  • 취소요청 상태: 횟수 차감 유지 (관리자 승인 시 복구)
  • 승인완료 상태: 횟수 차감
  • 취소완료/거부: 횟수 복구

Q4. 공지사항이 메인 페이지에 표시되지 않아요

A: 브라우저 캐시를 새로고침(Ctrl+F5) 하거나, 공지사항이 최근 작성된 것인지 확인하세요.

Q5. 팝업이 사용자에게 보이지 않아요

A: 다음을 확인하세요:

  • 팝업 활성화 상태가 ON인지
  • 현재 날짜가 시작일~종료일 범위 내인지
  • 사용자가 오늘 하루 보지 않기를 선택했는지

Q6. 특정 날짜의 예약을 모두 취소하고 싶어요

A: 예약 관리에서 해당 날짜를 필터링한 후 각 예약을 강제 취소하고, 설정에서 해당 날짜를 예약 불가로 설정하세요.

Q7. 관리자 비밀번호를 변경하고 싶어요

A: 현재는 데이터베이스를 통해서만 변경 가능합니다. 시스템 관리자에게 문의하세요.

Q8. 당일 알림톡 발송 시간을 변경할 수 있나요

A: vercel.json의 cron schedule 설정을 수정해야 합니다. 시스템 관리자에게 문의하세요.

현재 설정: 매일 오전 9시 (UTC 00:00 = 한국 시간 09:00)

Q9. 통계 데이터를 엑셀로 내보낼 수 있나요

A: 현재 버전에서는 지원하지 않습니다. 향후 업데이트 예정입니다.

Q10. 모바일에서도 관리자 기능을 사용할 수 있나요

A: 네, 반응형 디자인으로 모바일에서도 모든 기능을 사용할 수 있습니다. 다만 큰 화면에서 더 편리하게 사용 가능합니다.
